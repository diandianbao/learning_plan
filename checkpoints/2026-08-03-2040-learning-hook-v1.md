# learning_hook（学习召回 app）v1 完成

## 在做什么

用 Android 原生（Java + Views）完成"学习召回"app v1 全部四个里程碑，核心是用 GitHub 私有仓库做学习 checkpoint 的唯一事实源，手机端只做召回。M1 课题列表（Contents API 拉取 + 手工解析 frontmatter/三段式 + "台灯下的书桌"深色设计）、M2 详情页（三段式 + 私有仓库照片 Glide 鉴权加载）、M3 通知召回（WorkManager 15min 周期 + 指数退避降频）、M4 回忆页（随机抽旧问题 + 去做了/还没）。3 次提交 ~3000 行，19 个单测全过，模拟器全链路（列表→详情→通知→回忆）用真实私有仓库数据联调通过。

## 下一步动作

把 debug APK 装到华为真机实测：USB 调试连上电脑 `./gradlew installDebug`，授权通知权限后**把 app 加入电池优化白名单**（否则国产 ROM 会杀 WorkManager），验证通知在无聊时段真实弹出、点击直达详情页；真机访问 api.github.com 若不稳需配代理。装完真机后真实使用几天，每天看一次列表页的"凉了 N 天"变化。
